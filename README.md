# Yizhi Zhang 个人主页

## 本地查看
解压 ZIP，然后双击 index.html，用浏览器打开。无需安装任何软件。

## 修改文字
用记事本或 VS Code 打开 index.html，修改文字后保存并刷新浏览器。style.css 控制样式。

## 上传到 GitHub Pages
1. 登录 GitHub，新建 Public 仓库，名称为「你的实际 GitHub 用户名.github.io」。
2. 点击 Add file → Upload files，上传 index.html、style.css 和整个 assets 文件夹。网页文件和 assets 文件夹要放在仓库根目录，不要只上传 ZIP。
3. 点击 Commit changes。
4. 打开 Settings → Pages，Source 选择 Deploy from a branch，Branch 选择 main，Folder 选择 / (root)，保存。若默认分支不是 main，选择包含网页文件的实际分支。
5. 部署完成后，打开 https://你的实际GitHub用户名.github.io/。
